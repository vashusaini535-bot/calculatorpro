# MathMaster Pro - requirements
#
# Python 3.8 or newer is required.
#
# This app uses ONLY the Python standard library
# (tkinter, math, re, statistics, fractions), so there are
# no third-party packages to install with pip.
#
# tkinter ships with Python on Windows and macOS.
# On Linux, if you get "No module named tkinter", install it with:
#   Debian/Ubuntu : sudo apt install python3-tk
#   Fedora        : sudo dnf install python3-tkinter
#   Arch          : sudo pacman -S tk
